# AI Work OS

面向个人程序员、支持多项目和多仓库的智能工作平台。

平台管理工作目标、任务流程、权限、知识和验收；Codex、OpenCode 等 Agent 承担步骤内部的执行；优化中心依据可追溯的结果持续改进 Skill、知识和工作流。

## 开发运行

需要 Node.js 22.13 或更高版本以及 Git。

```sh
npm ci
npm run check
npm run dev
```

开发页面为 http://127.0.0.1:5173，API服务为 http://127.0.0.1:4310。生产方式在 `npm run build` 后执行 `npm start`，访问4310端口。

首次启动自动生成本机访问令牌，终端显示令牌文件位置；将该文件内容填入连接页。令牌只存于浏览器当前会话，不提交到仓库。默认运行数据在本机 `%LOCALAPPDATA%/AIWorkOS`（非Windows为 `~/.local/share/AIWorkOS`），可用 `AI_WORK_OS_DATA_DIR` 指定独立数据目录。不要将活跃状态库放进仓库或同步目录。

当前支持任务、项目和人工执行至交付验收闭环，Agent执行、诊断和优化评估仍在实现。[代码结构与实现进度](docs/代码结构与实现计划.md)列出完整剩余范围。设计稿中的容量、性能和评估阈值均为拟定目标，不代表实测结果。
