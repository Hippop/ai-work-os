# 代码结构与实现计划

更新：2026-11-08。产品要求以[完整设计稿](AI-Work-OS-设计稿-v1.0.md)为准。本文件记录实际代码与剩余工作，不能用已通过的局部测试推断整个产品已完成。

## 代码结构

```text
apps/server/app.ts           HTTP边界、鉴权、参数校验、静态页面服务
apps/server/index.ts         本机启动、运行目录、令牌与生命周期
apps/web/src/main.tsx        工作台、执行台、项目、优化概览
apps/web/src/style.css       桌面/移动布局
packages/domain/index.ts    领域类型、输入契约、状态转换
packages/persistence/       SQLite事务、实体、事件、幂等记录与outbox
packages/workflow/          任务准备、运行控制、交付、业务验收
tests/workflow.test.ts      状态/幂等/持久化/HTTP集成验证
apps/worker/index.ts        独立执行进程，步骤协议和Agent调用
packages/runtime/          Codex适配、进程树控制、调度监督器
packages/workspace/        Worktree创建、代码摘要、变更导出
tests/runtime.test.ts      真实子进程、隔离、测试失败、取消与产物校验
scripts/smoke-agent.ts     显式运行的真实Codex端到端冒烟检查
```

前端仅通过HTTP操作领域模型；控制服务唯一写库。实体JSON暂存在统一实体表中，事件、幂等和outbox独立建表；这是当前实现选择，设计稿中的完整关系约束尚待后续迁移。需要先补版本迁移机制，再扩展表结构。

下一步把前端拆为页面、表单、运行详情组件及独立API客户端；领域契约进一步拆分，避免单个入口文件随产品增长。

## 当前可用

- 创建任务、绑定已有Git项目，验证目标与验收清单。
- 人工任务执行准备、启动、暂停/恢复/取消、提交成果、接受/退回。
- 区分运行成功和业务验收；退回增加任务版本，历史运行保留。
- 运行状态机、事务追加事件、启动幂等、防止任务同时运行、准备摘要失效检查。
- 本机令牌鉴权、来源检查、输入校验、数据库持久化与重开恢复。
- 工作台、执行台、项目设置、真实样本计数与响应式布局。
- Codex可执行文件探测、独立Worker、outbox派发、运行隔离Worktree、六步骤固定开发流程。
- 项目级显式Agent授权和测试命令配置，运行时间预算，结构化输出，确定性测试，代码/产物摘要和下载校验。
- 等待进程树停止后再取消/释放工作区；重启后不明运行进入核对状态，不盲目重跑。
- 已通过一次真实Codex最小开发任务：隔离修改、测试、审查、交付，详见验证记录。
