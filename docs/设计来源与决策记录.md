## 2. 本次主要优化

| 原方案中的缺口 | 本次设计 | 设计稿位置 |
|---|---|---|
| 任务层级容易混淆业务与运行 | 子任务保留业务目标，运行步骤使用单独DAG | 第5章 |
| TaskRun和StepRun不足以描述重试 | 增加StepAttempt、PlanRevision、WorkspaceBinding | 第5–7章 |
| 回退可能擦除历史 | 用新图版本和追加修复步骤表达，旧证据显式失效 | 第7章 |
| Worktree容易被理解成权限沙箱 | 区分文件目录隔离、写租约、进程停止、权限执行 | 第8章 |
| Headless能力差异未明确 | Adapter能力矩阵及真实版本验证，不假设暂停/审计统一支持 | 第8章 |
| 执行失败与外部副作用结果不明未区分 | unknown状态、动作账本、幂等键、核对恢复 | 第9章 |
| 全过程记录可能超出执行器可观测范围 | 记录平台可见事实和覆盖缺口，不承诺内部推理日志 | 第12章 |
| 低风险定义不明确 | 依据行为、权限和影响范围分类，Skill文本不天然低风险 | 第13章 |
| 历史回放可能误触真实动作 | 区分事件回看和隔离执行回放，固定样本和模拟外部连接器 | 第13章 |
| 基础权限与恢复后置 | 最低授权、取消、持久化和恢复纳入M1 | 第17章 |
| 缺实现与验收依据 | 增补接口、表约束、目录、工作包和20项场景验收 | 第14–18章 |

这些是本次设计建议，不是已经实施的功能，也不是原对话逐条确认过的要求。
